# dotfiles

Declarative macOS and NixOS configurations.

## Apply the configuration

For the first Mac setup, select `personal` or `work`:

```sh
./setup.sh personal
```

After setup, use `reload!`. CI deploys `main` to the server through Cachix Deploy.
