# Repository instructions

Use ASD-STE100 Issue 9 for comments, documentation and human-readable messages.
Apply these rules to project Notion content and future text changes.
Use active voice. Limit instruction sentences to 20 words and descriptive sentences to 25 words.
Keep code identifiers, product names, paths, commands and API fields unchanged.
Do not change configuration behavior during a text-only edit.

Keep operational documentation in Notion. Do not recreate the docs folder.
Update the existing topic page. The README links to Mac setup, server operations and guest access.
Read the [Assistant guide](https://app.notion.com/p/3f92dfc5083e817c9d2ef80018efbe6b) for writing rules and documentation ownership.

This repository is public. Machine names, usernames, the owner's email addresses, public keys and disk IDs can be public.
Do not publish the email addresses of other people. Keep access endpoints in the private inventory.
Do not commit plaintext credentials or private keys. Public age encryption keys are permitted.
